# 🏫 School 61 Survey Bot

Telegram-бот для сбора анкет от родителей и учеников с записью в Google Sheets.

## Как работает

1. Директор генерирует ссылки-приглашения командой `/genlinks`
2. Учитель получает **две ссылки** — для родителей и для учеников — и рассылает каждой группе свою
3. Пользователь открывает бот по ссылке — роль зафиксирована, изменить нельзя
4. Бот собирает **Имя → Фамилия → Класс**, затем задаёт анкету
5. Ответы записываются в **Google Sheets** на два листа: «Родители» и «Ученики»

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone <repo-url>
cd school61
```

### 2. Установить зависимости

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Создать файл `.env`

Скопируйте пример и заполните своими значениями:

```bash
cp .env.example .env
```

Содержимое `.env`:

```
BOT_TOKEN=токен_от_BotFather
GOOGLE_CREDS_FILE=credentials.json
SPREADSHEET_NAME=Школьные анкеты
ADMIN_IDS=123456789
```

> Несколько админов через запятую: `ADMIN_IDS=111,222,333`

### 4. Настроить Google Sheets

#### 4.1 Google Cloud Console

1. Перейдите на [console.cloud.google.com](https://console.cloud.google.com)
2. Создайте проект → включите **Google Sheets API** и **Google Drive API**
3. Перейдите в **APIs & Services → Credentials → Create Credentials → Service Account**
4. Создайте аккаунт → вкладка **Keys → Add Key → Create New Key → JSON**
5. Переименуйте скачанный файл в `credentials.json` и положите рядом с `bot.py`

#### 4.2 Google Sheets

1. Создайте таблицу на [sheets.google.com](https://sheets.google.com)
2. Назовите её так же, как `SPREADSHEET_NAME` в `.env` (по умолчанию: **«Школьные анкеты»**)
3. Нажмите **Поделиться** → вставьте `client_email` из `credentials.json` → роль **Редактор**

### 5. Запустить бота

```bash
python bot.py
```

## Структура таблицы

Бот автоматически создаёт листы и шапку при первом ответе.

**Лист «Родители»** — 13 вопросов об атмосфере, учителях, внеклассной работе  
**Лист «Ученики»** — 10 вопросов о школе, учёбе, отношениях

Общие колонки: `Дата и время | Telegram ID | Username | Имя | Фамилия | Класс | …`

---

## Команды бота

| Команда | Кто | Описание |
|---------|-----|----------|
| `/start` | все | Начать анкету (требует ссылку-приглашение от учителя) |
| `/genlinks [Имя учителя]` | админ | Сгенерировать 2 ссылки — для родителей и учеников |
| `/listlinks` | админ | Показать все выданные ссылки |
| `/stats` | админ | Статистика ответов + ссылка на таблицу |

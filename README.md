# 🏫 School Survey Bot — с записью в Google Sheets

## Что делает бот

1. Спрашивает: родитель или ученик
2. Собирает **Имя → Фамилия → Класс**
3. Задаёт анкету (13 вопросов для родителей / 10 для учеников)
4. Записывает всё в **Google Sheets** — два листа: «Родители» и «Ученики»

---

## Шаг 1 — Создать Google Sheets и сервисный аккаунт

### 1.1 Открыть Google Cloud Console
Перейдите: https://console.cloud.google.com

### 1.2 Создать проект
- Нажмите «Создать проект» → введите любое название → «Создать»

### 1.3 Включить API
Перейдите в **APIs & Services → Enable APIs**:
- Найдите **Google Sheets API** → Enable
- Найдите **Google Drive API** → Enable

### 1.4 Создать сервисный аккаунт
1. Перейдите **APIs & Services → Credentials**
2. Нажмите **«+ Create Credentials» → Service Account**
3. Введите любое имя → «Create and Continue» → «Done»
4. Откройте созданный аккаунт → вкладка **Keys**
5. **Add Key → Create New Key → JSON** → скачается файл

### 1.5 Переименовать файл
Переименуйте скачанный файл в `credentials.json` и положите рядом с `bot.py`

### 1.6 Создать таблицу Google Sheets
1. Откройте https://sheets.google.com → создайте новую таблицу
2. Назовите её **«Школьные анкеты»** (точно так, как в `SPREADSHEET_NAME` в bot.py)
3. Нажмите **Share (Поделиться)**
4. Скопируйте email сервисного аккаунта из `credentials.json` (поле `client_email`)
5. Вставьте этот email в поле «Добавить людей» → роль **Редактор** → Готово

---

## Шаг 2 — Настроить bot.py

Откройте `bot.py` и замените:

```python
BOT_TOKEN         = "ВСТАВЬТЕ_ВАШ_ТОКЕН_СЮДА"   # токен от @BotFather
SPREADSHEET_NAME  = "Школьные анкеты"             # название вашей таблицы
```

---

## Шаг 3 — Установить зависимости и запустить

```bash
pip install -r requirements.txt
python bot.py
```

---

## Структура таблицы

Бот автоматически создаёт два листа и шапку:

**Лист «Родители»:**
| Дата и время | Telegram ID | Username | Имя | Фамилия | Класс | Атмосфера | ... |

**Лист «Ученики»:**
| Дата и время | Telegram ID | Username | Имя | Фамилия | Класс | Нравится ли школа | ... |

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начать заполнение анкеты |
| `/stats` | Статистика + ссылка на таблицу (для админа) |
